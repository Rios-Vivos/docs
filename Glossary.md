# Glosario

En esta página se archiva un glosario con todas las palabras o conceptos que requieran ser usados en los distintos proyectos.

## Términos y Definiciones

| Término | Definición |
|---------|-----------|
| Donadores | Personas u organizaciones que brindan apoyo financiero o en especie a un proyecto o causa. |
| Visitantes | Usuarios que acceden a un sitio web o espacio físico sin necesidad de registrarse o formar parte de una comunidad específica. |
| Academicos | Profesionales dedicados a la investigación y la enseñanza, generalmente vinculados a instituciones educativas o centros de estudio. |
| Comunidades | Grupos de personas que comparten intereses, objetivos o características comunes, organizadas para colaborar y compartir información. En nuestro caso, las personas que viven cercanas al Rio Santiago. |
| Monitoreo | Proceso continuo de observación y análisis del rendimiento, la seguridad y la disponibilidad de un sistema, aplicación o red para identificar y resolver problemas de manera proactiva. |
| Rios Vivos | Movimiento ambiental y social que lucha por la defensa de los ríos y el territorio frente a megaproyectos y extractivismo. |
| Un Salto de Vida | Organización dedicada a la defensa del medio ambiente y los derechos humanos, especialmente en la región de El Salto, Jalisco, México. |
| Feature | Funcionalidad específica de un software o sitio web que agrega valor o mejora la experiencia del usuario. |
| Wireframes | Representaciones visuales simples y esquemáticas de la estructura y disposición de una página web o aplicación. |
| Mockups | Diseños más detallados y realistas que muestran la apariencia final de una página o aplicación, incluyendo colores, tipografía y elementos gráficos. |
| Curaduria | Proceso de selección, organización y presentación de contenido relevante y de calidad en un entorno digital o físico. |
| Infraestructura | Conjunto de recursos físicos y virtuales necesarios para ejecutar aplicaciones, como servidores, redes y almacenamiento. |
| CI/CD | Práctica de desarrollo que automatiza la integración y entrega de código para garantizar actualizaciones rápidas y seguras. |
| Estrategia Web | Plan que define objetivos, herramientas y acciones para optimizar la presencia y el rendimiento de un proyecto en línea. |
| Sistema de Comunicacion | Conjunto de canales y herramientas utilizados para intercambiar información dentro de una organización o entre usuarios. |
| Pagina Dinamica | Sitio web cuyo contenido se genera y actualiza automáticamente según la interacción del usuario o la base de datos. |
| Pagina Web | Documento digital accesible a través de internet, compuesto por contenido multimedia y código HTML. |
| Landing Page | Página específica diseñada para captar la atención de los visitantes y guiarlos hacia una acción concreta, como registrarse o comprar. |
| Repositorio | Almacén digital donde se guarda, gestiona y versiona el código fuente de un proyecto. |
| TED Talk | Conferencia breve y enfocada en ideas innovadoras, presentada en el formato de la organización TED (Technology, Entertainment, Design). |
| Politica de Privacidad | Documento que explica cómo se recopila, utiliza y protege la información personal de los usuarios. |
| Politica de Datos | Normativa que define el manejo, almacenamiento y procesamiento de datos en un sistema o plataforma. |
| Politica de uso de cookies | Aviso que informa a los usuarios sobre el uso de cookies para recopilar información durante la navegación. |
| Facturas | Documentos legales que detallan la transacción de un producto o servicio, incluyendo costos e impuestos aplicables. |
| AWS | Plataforma de servicios en la nube que ofrece almacenamiento, computación y bases de datos bajo demanda. |
| S3 | Servicio de almacenamiento de objetos de AWS, utilizado para guardar y recuperar grandes volúmenes de datos. |
| Cloudflare | Plataforma que proporciona seguridad, rendimiento y distribución de contenido para sitios web a través de una red global de servidores. |
| EC2 | Servicio de AWS que permite ejecutar instancias virtuales de servidores con recursos configurables. |
| Node JS | Entorno de ejecución para JavaScript en el lado del servidor, ideal para construir aplicaciones escalables y en tiempo real. |
| JavaScript | Lenguaje de programación utilizado para crear interactividad y dinamismo en sitios web. |
| CSS | Lenguaje de diseño utilizado para controlar la apariencia y el estilo de las páginas web. |
| Bootstrap | Framework de código abierto que facilita el desarrollo de sitios web responsivos y bien diseñados. |
| Next JS | Framework de React que permite el desarrollo de aplicaciones web optimizadas y con renderizado del lado del servidor. |
| Provedor de Pagos | Plataforma o servicio que permite procesar transacciones electrónicas, como Stripe, PayPal o MercadoPago. |
| HTML | Lenguaje de marcado utilizado para estructurar el contenido de las páginas web. |
| Framework | Conjunto de herramientas, bibliotecas y convenciones que facilitan el desarrollo de software, proporcionando una estructura base. |
| RAG | "Retrieval-Augmented Generation" (Generación Aumentada por Recuperación), una técnica que combina modelos de lenguaje grandes (LLM) con fuentes de datos externas para mejorar la precisión y relevancia de las respuestas. |
