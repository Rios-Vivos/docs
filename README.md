# Documentación del proyecto

- `SRS.md`: especificación de requisitos, contexto y arquitectura.
- `Glossary.md`: glosario de términos usados en el proyecto.
- `Features/`: fichas de alcance, reglas y entregables de cada feature.
- `plantuml/`: diagramas de base de datos y seguridad en formato PlantUML.
- `img/`: recursos gráficos utilizados en los documentos.
- `Files/`: materiales de referencia (PDF/DOCX) asociados.
