# Feature: Fixes urgentes

**Status:** Historical reference, not evidence that every reported fix remains
implemented. Verify behavior in the owning repository before closing a related
issue.

The original defect report is attached as
[`Files/Deficiencias de la pagina.docx`](../Files/Deficiencias%20de%20la%20pagina.docx).

For every urgent fix, record the issue, owning repository, affected route or
component, reproduction steps, expected behavior, test/verification evidence,
deployment or rollback notes, and final status. Cross-project fixes must also
identify affected API, admin, public-site, firmware, or infrastructure
consumers.
